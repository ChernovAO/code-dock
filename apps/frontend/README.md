# Code Dock Frontend

Мобильный веб-интерфейс Code Dock на React + TypeScript.

## Зачем нужен
- Показывает репозитории, проекты, чаты и файлы.
- Общается только с бэкендом (`apps/core`). С opencode напрямую не связан.
- Проектируется mobile-first: сначала телефон, потом остальное.

## Чего здесь нет
- Своего ИИ-агента. Вся логика ИИ живёт в opencode.
- Авторизации. Способ защиты доступа пока не выбран.

## Запуск
Команды появятся вместе с кодом. Приложение запускается через `docker compose up` из корня репозитория.
