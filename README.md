# Code dock
Этот проект это моя попытка сделать удобный для меня инструмент для работы с ИИ агентом с телефона. Обёртка над связкой из opencode и git.

## Идея
Я хочу иметь возможность работать с ИИ с своего телефона. Для этого мне нужен Web UI похожий на Open Web UI, но с расширенными возможностями в плане сохранения файлов и ведения проектов. Так же я хочу вести версионирование через git и синхронизироваться с github. Сейчас вся работа с ИИ у меня ведётся или через бесплатные web чаты или через opencode на ноутбуке. Поэтому моё решение будет обёрткой над opencode и git.
